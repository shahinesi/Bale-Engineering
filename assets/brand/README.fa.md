# فایل‌های هویت بصری

این فایل‌ها طراحی اختصاصی پروژه Bale Engineering هستند و لوگو یا اسکرین‌شات رسمی بله محسوب نمی‌شوند.

- <code>mark.svg</code>: نشان کوچک پروژه.
- <code>hero.svg</code>: تصویر معرفی نسخه انگلیسی README.
- <code>hero-fa.svg</code>: تصویر معرفی نسخه فارسی README.

تصاویر باید برداری، مستقل و دسترس‌پذیر باقی بمانند. هنگام استفاده در Markdown متن جایگزین معنادار اضافه کنید. اسکریپت، Tracker یا وابستگی خارجی به SVGها اضافه نکنید.
