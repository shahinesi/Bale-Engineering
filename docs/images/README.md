# Architecture images

[فارسی](README.fa.md) · **English**

The SVG files in this directory are explanatory illustrations of the reference architecture.

- `architecture-overview-en.svg` — English conceptual architecture.
- `architecture-overview-fa.svg` — Persian conceptual architecture.

They are not screenshots and do not claim to represent a deployed production environment. The editable source of truth remains the Mermaid and Markdown files under `docs/`.
