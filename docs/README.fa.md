## قواعد مشارکت در مستندات

- سورس Mermaid باید قابل‌ویرایش و همراه مستندات نگهداری شود.
- نسخه فارسی و انگلیسی باید هم‌زمان با تغییر معماری یا رفتار سیستم به‌روزرسانی شوند.
- برای تصاویر معماری از SVG استفاده کنید و برای هر تصویر متن جایگزین معنادار بنویسید.
- نمودار مفهومی را به‌عنوان معماری پیشنهادی معرفی کنید، نه استقرار تأییدشده Production.
- تصویر تولیدشده را به‌جای اسکرین‌شات واقعی بله یا محصول جا نزنید.
- پیش از Merge، نمودار را در GitHub بررسی کنید.
